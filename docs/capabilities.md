# Capability tables

Generated by `cargo run --example capabilities`.
`tests/capability_report.rs` performs every advertised operation, so a row that overstates itself fails the test suite.

## Build features

| feature | enabled here | effect |
| --- | --- | --- |
| `post-quantum` | no | ML-DSA and composite signature algorithms, and their key generation |
| `deprecated` | no | legacy identifiers this crate otherwise refuses: `RSA-OAEP` (SHA-1 label) and the `none` algorithm identifier |

## Key formats

| identifier | status | operations | note |
| --- | --- | --- | --- |
| `JWK (JSON)` | supported | import, export | Jwk::from_json / Jwk::to_json |
| `PKCS#8 DER / "PRIVATE KEY"` | supported | import, export | RSA, EC P-256/P-384/P-521, Ed25519, X25519; export emits the narrower OneAsymmetricKey form (ADR 0022) |
| `SPKI DER / "PUBLIC KEY"` | supported | import, export | OKP/X25519 has no SPKI form in this backend and is refused by name |
| `PKCS#1 DER / "RSA PRIVATE KEY"` | supported | import | rebuilt from its parts and checked against itself (ADR 0023); multi-prime is refused |
| `PKCS#1 "RSA PUBLIC KEY"` | supported | import | import only; export uses SPKI |
| `SEC1 DER / "EC PRIVATE KEY"` | supported | import | must state its curve by name; explicit parameters are refused (ADR 0024) |
| `Encrypted PKCS#8 / "ENCRYPTED PRIVATE KEY"` | supported | import, export | PBES2 + PBKDF2-HMAC-SHA2 + AES-CBC only, with a bounded work budget (ADR 0025) |
| `X.509 certificate / "CERTIFICATE"` | supported | import | subject public key only; validates nothing about the certificate (ADR 0026) |
| `PKCS#12 / JWK Set encryption` | recognized, unsupported | — | not implemented; a JWK Set is read as plain JSON only |
| `password-protected legacy PEM (Proc-Type/DEK-Info)` | recognized, unsupported | — | recognized by the armor reader and refused: the encryption is its own key material, not a JOSE input |
